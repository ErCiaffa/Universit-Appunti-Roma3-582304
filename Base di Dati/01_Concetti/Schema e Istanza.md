# 📐 Schema e Istanza

La distinzione fondamentale tra la struttura di una base di dati e i dati reali memorizzati.

- **Schema (Intensione):** Rappresenta l'aspetto strutturale, invariante nel tempo. Definisce i nomi delle tabelle e dei relativi attributi.
  - *Esempio:* `Studenti(Matricola, Cognome, Nome)`
- **Istansion / Istanza (Estensione):** L'insieme dei dati (ennuple/righe) effettivamente contenuti nelle tabelle in un determinato istante di tempo. Varia continuamente in seguito alle operazioni di inserimento, modifica ed eliminazione.
