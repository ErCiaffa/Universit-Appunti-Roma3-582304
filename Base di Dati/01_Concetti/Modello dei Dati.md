# 💡 Modello dei Dati

Insieme di costrutti utilizzati per organizzare e strutturare la conoscenza e i dati all'interno di un sistema informativo.

### Concetti Chiave:
- **Modello Logico:** Rappresentazione astratta dei dati visibile all'utente/programmatore, indipendente dalle strutture fisiche di memorizzazione su disco.
- **Indipendenza dei Dati:** Permette di modificare la gestione fisica dei dati (es. file, indici su disco) senza dover modificare la struttura logica o le query delle applicazioni.
